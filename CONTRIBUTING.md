# Contributing

Thanks for helping improve these learning notes.

## Write-up checklist

- [ ] Challenge/version and official source link are clear.
- [ ] Environment and tool versions are recorded.
- [ ] Static and/or dynamic analysis steps are reproducible.
- [ ] Evidence supports each important conclusion.
- [ ] Any bypass or script is explained, not just pasted.
- [ ] The solution was tested from a clean starting state.
- [ ] Spoilers are clearly labelled.
- [ ] No challenge binaries or unlicensed third-party content are included.
- [ ] References point to the original source where possible.

## Suggested workflow

1. Create a branch: `writeup/<challenge>-<topic>`.
2. Add or update the relevant `writeups/<platform>/<challenge>/README.md`.
3. Put screenshots in `assets/screenshots/<challenge>/` and reference them with relative paths.
4. Open a pull request with a short summary and testing notes.

Use Markdown, redact personal tokens/keys, and never include real credentials or sensitive data from unrelated apps.
